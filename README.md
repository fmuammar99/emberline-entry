EMBERLINE — a round-based tactical FPS: one attacker vs four defender bots, bomb plant/defuse, economy and buy menu, in a dusk industrial yard. Built with Three.js 0.187.0.

## Run it

```sh
node serve.ts --port 8080
# then open http://127.0.0.1:8080 in desktop Chrome
```

Controls: WASD move, mouse look, click fire, R reload, G grenade, E plant, 1–4 weapons, B buy menu.
